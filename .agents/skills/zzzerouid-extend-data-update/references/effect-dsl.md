# extend_data DSL

`enka_to_mys.py` 注释（招式字母）与 `add_buff_props`（`Name+Value`，`Value` 加到 `props[Name]`）是编码约束。

## 词条形状

```text
[PREFIX:]StatName+Value
```

多条用 `;` 连接。`Value` 为整数；减益为负数（`D+-2500`、`FireResist+-1500`）。

## 招式前缀（字母序 `AXSBCWQPE`）

来源：`utils/enka_to_mys.py` 文件头注释。多个招式按此序拼接，不要按文案出现序。

| 字母 | 招式 |
|------|------|
| A | 普通攻击 |
| X | 冲刺攻击 |
| S | 闪避反击 |
| B | 特殊技 |
| C | 强化特殊技 |
| W | 连携技 |
| Q | 终结技 |
| P | 快速支援 / 极限支援 / 招架支援 / 回避支援 |
| E | 追加攻击 / 支援突击。文案「支援攻击」→ `PE` |

例：普攻+冲刺+闪避反击 → `AXS`；特殊技+强化特殊技 → `BC`；连携+终结 → `WQ`。

前缀加在 **被加伤的招式** 上（`[普通攻击]造成的伤害提升` → `A:DmgBonus`）。  
「发动[强化特殊技]时攻击力提升」这种 **自身面板** 通常不加前缀。  
「分别为」按招式分层（啄木鸟）→ 前缀加在 `AttackAdd` 上，层数 = 招式数。  
泛用 `DmgBonus` 且由特定招式触发（月相-晦）→ 触发招式作前缀。

## StatName

| 中文 | 键 | 量纲 |
|------|----|------|
| 攻击力 % | `AttackAdd` | 8% → 800 |
| 攻击力 点 | `Attack` | 原值 |
| 防御力 % | `DefenceAdd` | 16% → 1600 |
| 生命值 % | `HpAdd` | 10% → 1000 |
| 冲击力 % | `BreakStunAdd` | 6% → 600 |
| 冲击力 点 | `BreakStunBase` | 原值（加在基础冲击上） |
| 暴击率 | `Crit` | 8% → 800 |
| 暴击伤害 | `CritDmg` | 50% → 5000 |
| 穿透率 | `PenRate` | 8% → 800 |
| 能量自动回复 % | `SpRecoverAdd` | 20% → 2000 |
| 异常精通 点 | `ElementMystery` | 30 → 30 |
| 异常掌控 % | `ElementAbnormalPowerAdd` | 8% → 800 |
| 异常掌控 点 | `ElementAbnormalPower` | 原值 |
| 物理/火/冰/电/以太/风伤 | `PhysDmgBonus` 等 | 10% → 1000 |
| 泛用伤害 | `DmgBonus` | 15% → 1500 |
| 护盾量 | `ShieldAdd` | 15% → 1500 |
| 无视/降低防御 | `D` | 25% → `-2500`（写成 `D+-2500`） |
| 无视/降低属性抗 | `FireResist` 等 | 15% → `-1500` |

百分比：**数值 × 100**（游戏内 8% = DSL `800`，与面板万分比一致）。`8/16%` 取 **最大档**。

## `normal_effect` vs `skill_effect`

| | 放哪 |
|--|------|
| 无条件自身属性（暴击率+8%、物理伤害+20%） | `normal_effect` |
| 发动/命中/触发/后场/背后/入场后的加成 | `skill_effect` |
| `[某招式]造成的伤害提升`（即使常驻） | `skill_effect` + 前缀 |
| 阈值常驻（异常掌控≥115 则暴伤+30%） | `normal_effect` |
| 叠层额外段且带「最多叠加」（混沌重金属 5.5%×6） | 基础在 `normal_effect`，额外在 `skill_effect` |
| 同一增益被额外抬一次、无独立叠层（极地 20%+20%） | 合成满值进 `skill_effect` |

驱动盘：`desc1` = 2 件，`desc2` = 4 件。4 件文案可拆进 `normal` 与 `skill` 的 `desc2`。

音擎：`"1"`…`"5"` 对应 `talents` 精炼 1–5，各解析一遍（不要按精炼 1 线性推）。

## 叠层

- `最多叠加 N 层`：单层值 × N。
- `分别为` + 多个招式：层数 = 招式数（啄木鸟 9%×3 = 27% → `ASC:AttackAdd+2700`）。
- `叠满时额外提升 X%`：加到满层值上。

## 不编码

失衡值、异常积蓄效率/抗性、能量点数或点/秒、贯穿伤害、受伤降低、持续时间、内置 CD、全队唯一、测试/占位道具。

## JSON 形态

音擎：

```json
"钢铁肉垫": {
  "normal_effect": { "1": "PhysDmgBonus+2000", "2": "...", "3": "...", "4": "...", "5": "..." },
  "skill_effect":  { "1": "DmgBonus+2500", "2": "...", "3": "...", "4": "...", "5": "..." }
}
```

驱动盘：

```json
"啄木鸟电音": {
  "normal_effect": { "desc1": "Crit+800", "desc2": "" },
  "skill_effect":  { "desc1": "", "desc2": "ASC:AttackAdd+2700" }
}
```
